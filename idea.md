Problem
When using a Mac from a few meters away—e.g. sitting on a couch with a Bluetooth Magic Keyboard—the screen may be perfectly visible for watching videos, but text fields such as a browser address bar or search box are too small to comfortably read while typing.

Idea
A macOS utility that provides a temporary, full-screen or large text input overlay with a very large font.

Flow

1. Place the cursor in any text field.
2. Press a global keyboard shortcut.
3. A large temporary text editor appears.
4. Type while seeing the text clearly from a distance.
5. Optionally increase/decrease the font size.
6. Press another shortcut (or Enter) to close the overlay and automatically paste/insert the text into the original field where the cursor was.

Core value
Makes keyboard-based Mac control practical from across the room without needing to move closer to the screen just to read small text while typing.
